# Lab 4 — Multiplexer and Demultiplexer

## Objective

Design and simulate multiplexer and demultiplexer circuits using Verilog HDL.

## Files

- `mux.v` — Multiplexer implementation.
- `demux.v` — Demultiplexer implementation.
- `mux_demux_tb.v` — Testbench for verification.

## Concepts Covered

- Multiplexer
- Demultiplexer
- Data selection and routing
- Combinational logic
- Verilog HDL simulation
