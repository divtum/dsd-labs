# Lab 1 — Basic Gates

## Objective

Implementation and simulation of basic digital logic gates using Verilog HDL.

## Files

- `basic_gates.v` — Verilog implementation of basic logic gates.
- `bg_testbench.v` — Testbench used to verify the gate implementations.

## Concepts Covered

- AND gate
- OR gate
- NOT gate
- Basic Verilog HDL modeling
- Testbench-based simulation
