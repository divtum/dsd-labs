# Lab 2 — Half Adder and Half Subtractor

## Objective

Design and simulate half adder and half subtractor circuits using Verilog HDL.

## Files

- `ha.v` — Half adder implementation.
- `hs.v` — Half subtractor implementation.
- `ha_hs_tb.v` — Testbench for verification.

## Concepts Covered

- Half adder
- Half subtractor
- Sum and carry generation
- Difference and borrow generation
- Verilog testbench and simulation
